# 🏥 Smart Hospital Management System

A backend REST API for managing hospital operations such as users, patients,
doctors, departments, appointments, medical reports, and prescriptions.

## 🚀 Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Spring Security
- JWT Authentication
- BCrypt Password Encryption
- Bean Validation
- Swagger / OpenAPI
- Maven
- JUnit
- Mockito
